# 3640 Cloud Computing — Study Guide

A 5-week guide built from the notes, textbook chapters, and labs in this repo. Each week has learning objectives, a concept deep dive, a repository tour, practical takeaways, and a 5-question quiz with a hidden answer key.

## How to use this guide

1. Read the source files listed for the week first (this mirrors the course's flipped-classroom setup in `README.md`).
2. Work through the guide's deep dive with the source file open beside it.
3. Take the quiz **before** opening the answer key.
4. Do the hands-on parts in your Linux environment and AWS account — and always log in as your IAM user, not root.

> **Cost reminder:** terminate EC2 instances and release Elastic IPs when you finish a lab. Idle resources can still bill you.
