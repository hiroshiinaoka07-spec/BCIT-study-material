Installing and Configuring Hyper-V 
 
Hyper-V is a virtualization platform that is built into Windows Sever. Not only you can use Hyper-
V to host VMs and containers, but also it is integrated into the very fabric of Microsoft’s Azure 
Cloud computing environment. Actually, your client operating system such as Windows 10 also 
support Hyper-V but you have to enable the Hyper-V features. (Note: Before you work on the lab, 
make sure you have already known the following terms: Hypervisor, Hypervisor Type 1 vs Type 2, 
Virtualization, and Snapshots) 
Learning Objectives 
After completing this lab, you should be able to: 
• 
Verify the installation of Hyper-V server role. 
• 
Configure Hyper-V networks (Private, Public, Internal)) 
• 
Create and configure virtual machines. 
• 
Troubleshoot Hyper-V issues.
