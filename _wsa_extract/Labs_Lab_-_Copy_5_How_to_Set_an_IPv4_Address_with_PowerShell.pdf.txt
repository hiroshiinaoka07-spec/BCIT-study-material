How to Set an IPv4 Address with PowerShell  
Server Core is a more security-enhanced, less resource-intensive installation option (lower consumption 
of CPU, RAM, and disk space) than the Desktop Experience installation. Since server core is GUI-less 
OS, how to manage server core is big challenge for Sysadmin. You can manage it remotely by using one 
of the remote management options (Remote Server Administration Tools: RSAT) or you can manage 
Server Core locally by using Windows PowerShell (Enter-PSSession) or a command-line interface. You 
should know how to use PowerShell to install and configure services. You are going to learn how to use 
PS to set up an IP address this week. 
Learning Objectives 
• 
Learn how to use PS to configure an IP address for your server. 
• 
Trouble shooting IPv4 or IPv6 issues 
Network Topology 
 
Preparations 
1. Remove your Client IPv4 address 
2. Follow the network topology to connect your client1 and Svr1 to Switch (NAT 9) 
3. Configure Windows Firewall (Svr1 and Client1) to allow pings
