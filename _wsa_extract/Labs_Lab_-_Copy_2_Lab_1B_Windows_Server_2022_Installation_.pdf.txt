Task 5: Clone a new VM 
1. Go to the command (cmd) prompt, not PowerShell. Run the following command:
Sysprep /generalize /shutdown /oobe
Note: Microsoft’s System Preparation Utility (Sysprep.exe) prepares a Windows computer for 
cloning by removing specific computer information such as computer name and Security 
Identifier (SID). SysPrep is a built-In tool that comes with Windows since the release of 
Windows Server 2003 and Windows XP Professional and used for cloning and pre- 
configuration of a master Operating System Image. 
Note: You will have to be in the C:\Windows\System32\sysprep directory to run the sysprep 
command. You also can directly double click sysprep.exe to run (See the figure below) 
2. After you run sysprep, the VM will shut down automatically.
3. Select Win2022-Base Image and Right click and choose ->manage->clone->Manage-
>Clone Note: Make sure that you have to shut down your VM.
