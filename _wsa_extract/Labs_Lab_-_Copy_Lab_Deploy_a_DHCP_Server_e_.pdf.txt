DHCP Server 
All network clients need to have unique IP addresses assigned to their network interfaces. 
Manually assigning addresses and tracking the information can be arduous, even in small 
networks. Dynamic Host Configuration Protocol (DHCP) plays an import role in a typical 
network infrastructure. It provides an automated means of distributing important network 
configuration information to network clients, and it provides configuration information to other 
network-enabled services.  
Learning Objectives 
After completing this lab, you will be able to: 
• Install and configure the DHCP server role on Ca-Van-Svr1 
• Configure DHCP scopes 
• Validate the DHCP deployment

Task 2: Authorizing a DHCP Server 
 
 
 
In Active Directory Domain Services (AD DS) environments, domain-joined Windows 
DHCP servers must be authorized to service DHCP client requests. By forcing DHCP servers to 
be authorized, clients are protected from rogue domain-joined Windows DHCP servers that 
might maliciously affect network clients. Notes that this authorization does not prevent rogue

Task 3: Create a DHCP Scope and Testing 
To create a DHCP scope, perform the following steps. 
1. Log on your DHCP Server (Computer Name: Ca-Van-Svr1) running Windows Server 
2019 as domain administrator (Adatum\administrator) with the password. 
2. Click Start and click Server Manager. 
3. Click Tools > DHCP. 
 
4. Expand the server (Ca-Van-Svr1.adatum.com) node and the IPv4 node. 
 

--- page 9 ---

5. Right-click the IPv4 node and choose New Scope. 
 
6. In the New Scope Wizard, on the Welcome to the New Scope Wizard page, click Next. 
7. On the Scope Name page, in the Name text box, type a descriptive name and click Next. 
 
Note: Make sure to use a meaningful name and add description.  

--- page 10 ---

8. On the IP Address Range page, in the Start IP address text box, type the first in the range 
of addresses you want to assign. In the End IP address text box, type the last address in 
the range. 
9. In the Subnet mask text box, type the mask value for the subnet on which the scope will 
operate and click Next.  
 
Note: You can create a new scope. You also can use all IPs (1~254) and then add several 
exclusions in order to reserve IPs for you member servers. 
10. On the Add Exclusions and Delay page, in the Start IP address and End IP address text 
boxes, specify a range of addresses you want to exclude from the scope. You can also 
specify a delay interval between the server’s receipt of DHCPDISCOVER messages and 
its transmission of DHCPOFFER messages. Then, click Next.
