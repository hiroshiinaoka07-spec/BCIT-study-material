Linux VMware Workstation Pro Installation 
 
Example: How to install VMware-Workstation-Full-14.1.3-9474260.x86_64.bundle 
 
Installation with root password 
 
Su            // login Root 
***** 
cd Downloads/ 
 
ls -l VMware-Workstation-Full-14.1.3-9474260.x86_64.bundle 
 
 
 
Note:(-rw-r—r--) 
 
chmod a+x VMware-Workstation-Full-14.1.3-9474260.x86_64.bundle 
 
ls -l VMware-Workstation-Full-14.1.3-9474260.x86_64.bundle 
 
 
 
Note:(-rwxrwxr-x.) 
 
./ VMware-Workstation-Full-14.1.3-9474260.x86_64.bundle 
 
yum install kernel-devel 
 
You may not need the following command lines  
 
yum install gcc-c++ 
 
yum install kernel-devel-3.10.0-693.el7.x86_64 
 
Installation without root password 
cd Downloads/ 
sudo bash ./ VMware-Workstation-Full-14.1.3-9474260.x86_64.bundle
