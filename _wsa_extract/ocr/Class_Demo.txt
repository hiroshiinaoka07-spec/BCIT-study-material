The Domain Name System (DNS) is the foundation name service in the Win2012 OS. A
DNS server responds to name and IP address resolution quenes (recursive queries and iterative
queries) from the DEN client service (Services. MSc->DNS Client). IT also enables DNS clients
to locate network services, such as Active Directory Domain Services (AD DS) domain
controllers, Global Catalog services (GC), and messaging servers. If you configure your DNS
infrastructure inappropriately or it is not working correctly, these important network service will
be inaccessible to your network servers and clients. Therefore, it is vital that you understand how
to deploy, configure, manage, and troubleshoot this critical service.
